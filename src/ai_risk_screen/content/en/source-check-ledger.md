# Source-check ledger template

Every factual claim, number, date, or translation in AI-assisted output must be checked against a trusted source before use.

| # | Claim or number in output | Trusted source | Source URL (https only) | Checker | Date | Result |
|---|---------------------------|----------------|-------------------------|---------|------|--------|
| 1 | | | | | | pass / fail / not found |
| 2 | | | | | | |
| 3 | | | | | | |

## Rules

- **Pass:** Claim matches the trusted source exactly or within stated rounding.
- **Fail:** Claim contradicts the source; do not use the output without correction.
- **Not found:** Source does not contain the claim; treat as unverified; do not publish.

Log failures and near-misses in the pilot close-out (field 10).
